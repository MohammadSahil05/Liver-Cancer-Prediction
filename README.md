# 🏥 Liver Cancer Prediction System

Machine Learning-based healthcare project for predicting liver cancer using patient medical data.

---

## 🚀 Overview

This project uses Machine Learning algorithms to analyze medical datasets and predict the likelihood of liver cancer. The goal is to assist healthcare professionals by providing early prediction support.

---

## ✨ Features

- Medical Data Analysis
- Data Preprocessing
- Feature Selection
- Machine Learning Prediction
- Model Evaluation
- Data Visualization

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Machine Learning
